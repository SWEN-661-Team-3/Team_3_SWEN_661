# React + Vite 
SWEN 661 - Team 3 environment setup for web-browsers.

## Run

```bash
npm install
npm run dev
```

Opens at http://localhost:5173

## Offline behavior

Supported React routes continue to load from the cached `/index.html` application shell when offline. While viewing cached content, the app displays an in-app offline notice. The static `/offline.html` page is used only when a navigation cannot reach the network and the cached application shell is unavailable.
